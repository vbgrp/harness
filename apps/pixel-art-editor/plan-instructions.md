## 요구사항 (사용자 요청)
- 16x16 격자에 클릭/드래그로 도트를 찍어 그림을 그릴 수 있어야 한다.
- 완성한 그림을 PNG 파일로 저장(다운로드)할 수 있어야 한다.
- 색상 팔레트가 있어야 한다 (기본 색상 선택 + 커스텀 색상 선택 가능하면 좋음).
- 모바일에서도 사용 가능해야 한다 (터치 지원).
- 외부 라이브러리 사용 최소화 (CDN은 허용되지만 이 앱은 바닐라 JS로 충분함).
- 앱은 `/apps/pixel-art-editor/` 폴더 안에서 완전히 독립적으로 동작해야 하며, 블로그의
  다른 파일(`index.html`, `apps/2048/*` 등)은 건드리지 않는다.

## spec.md에 포함할 내용
1. 앱 개요 (한 문단)
2. 파일 구조 (`apps/pixel-art-editor/` 하위에 어떤 파일들을 만들지 - 예: index.html, style.css, script.js)
3. 주요 기능 목록과 각 기능의 동작 방식
   - 16x16 격자 렌더링 방식 (예: CSS grid + div, 또는 canvas)
   - 도트 찍기: 클릭, 드래그(마우스 다운 상태에서 이동), 터치 지원
   - 색상 팔레트: 프리셋 색상 목록 + `<input type="color">` 커스텀 선택
   - 지우개 기능
   - 전체 지우기(Clear) 기능
   - PNG 저장: canvas를 이용해 16x16 픽셀 데이터를 실제 이미지로 변환 후 다운로드 (확대 배율 옵션 등)
   - (선택) 실행 취소(undo) 등 추가 기능이 있다면 명시
4. UI 레이아웃 개요 (격자, 팔레트, 버튼들의 배치)
5. 모바일 대응 방안
6. 파일별 대략적인 책임 분담
