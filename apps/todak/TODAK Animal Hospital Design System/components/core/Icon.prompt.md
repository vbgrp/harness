Line icon wrapper — use anywhere a glyph is needed; never hand-draw SVG or use emoji.

```jsx
<Icon name="stethoscope" size={24} color="var(--frost-800)" />
```

Common names: paw-print, stethoscope, syringe, pill, heart-pulse, calendar-check, sprout, phone, clock, map-pin, dog, cat.
Stroke is always 2 (brand `--stroke-icon`); only raise it for oversized display glyphs.
