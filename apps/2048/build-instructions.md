## 목표

## 범위 (반드시 지킬 것)

- 순수 HTML/CSS/JavaScript만 사용한다. 외부 라이브러리는 쓰지 않는다 (CDN도 이 정도 게임엔 불필요).

  - `D:\Claude_code\Harness\apps\2048\script.js`

- `plan-instructions.md`, `spec.md`는 그대로 둔다 (수정/삭제 금지).

## 구현 요구사항 (spec.md 요약, 반드시 반영)
- 4x4 그리드, 방향키(↑↓←→)로 타일 이동, 동일 숫자 타일 충돌 시 병합.
- 이동/병합은 "왼쪽 이동" 공통 함수를 회전/반전시켜 4방향에 재사용하는 방식으로 구현해 중복을 줄인다.
- 이동이 실제로 발생했을 때만 빈 칸에 새 타일(90% 확률 2, 10% 확률 4) 생성.
- 점수판: 현재 점수(SCORE)와 최고 점수(BEST, localStorage에 저장/복원).
- 2048 타일 생성 시 승리 오버레이("You Win!" + 계속하기/새 게임), 더 이상 이동 불가 시 게임 오버 오버레이("Game Over!" + 다시 시작).
- 방향키 입력 + 모바일 터치 스와이프 입력 둘 다 지원 (`touchstart`/`touchend`로 스와이프 방향 판정, `preventDefault`로 스크롤 방지).
- "New Game" 버튼으로 언제든 즉시 재시작.
- 반응형: 모바일 화면에서도 보드가 잘리지 않도록 `min(90vw, 90vh, 500px)` 류의 CSS로 정사각형 보드 유지, 뷰포트 메타 태그 포함.
- 값별 타일 색상(2~2048 각각 다른 색), 128 이상은 흰 글씨/그 이하는 진한 갈색 글씨로 대비 확보.
- 신규/병합 타일에 간단한 팝인/펄스 애니메이션 (슬라이드 이동 애니메이션은 선택사항, 시간 되면 추가).

## 완료 기준
- 브라우저에서 열었을 때 방향키로 타일이 이동/병합되고 점수가 오르는지 동작해야 한다.
- 문법 오류나 콘솔 에러가 없어야 한다.
- 작업이 끝나면 만든 파일 목록과 핵심 구현 내용을 간단히 보고한다. (Review는 별도 서브에이전트가 담당하므로 직접 브라우저 테스트는 하지 않아도 된다.)
