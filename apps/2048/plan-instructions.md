# 지침: 2048 게임 웹앱 — Plan 단계

## 배경
이 저장소는 마크다운 기반 블로그 + 미니 웹앱 포트폴리오다. 프로젝트 루트의 CLAUDE.md에 정의된 작업 사이클(Plan → Build → Review → Embed)을 따른다. 지금은 Plan 단계만 수행한다.

## 목표
사용자 요청: "2048 게임을 만들어줘. 방향키로 숫자 타일을 밀어서 합치는 퍼즐 게임이야. 점수판도 넣어줘."

- 4x4 그리드에서 방향키(↑↓←→)로 타일을 민다.
- 같은 숫자 타일이 부딪히면 합쳐지며 점수가 올라간다.
- 매 턴마다 빈 칸에 새 타일(2 또는 4)이 무작위로 생성된다.
- 점수판(현재 점수, 가능하면 최고 점수 localStorage 저장)을 표시한다.
- 2048 타일 생성 시 승리, 더 이상 움직일 칸이 없으면 게임 오버 처리.

## 범위
- 순수 HTML/CSS/JavaScript만 사용 (CLAUDE.md 규칙). 외부 라이브러리 최소화, CDN은 허용되지만 이 정도 게임은 불필요할 가능성이 높다.
- 모바일에서도 동작해야 하므로 터치 스와이프 조작도 고려한다.
- 앱은 `/apps/2048/` 폴더 안에 완전히 자체 완결되어야 한다 (블로그의 다른 파일은 건드리지 않음).

## 해야 할 일
1. 어떤 화면 구성(레이아웃), 어떤 파일 구조(`index.html`, `style.css`, `script.js` 등)로 만들지 정리한다.
2. 핵심 로직(그리드 상태 관리, 이동/병합 알고리즘, 랜덤 타일 생성, 승리/패배 판정, 점수 계산 및 localStorage 저장)을 어떻게 구현할지 간단히 설명한다.
3. UI/UX 요소(타일 색상, 애니메이션 여부, 반응형 레이아웃, 재시작 버튼 등)를 정리한다.
