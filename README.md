# My Blog & Apps

마크다운 기반 블로그 + 미니 웹앱 포트폴리오. HTML, CSS, JavaScript만 사용합니다.

## 구조

```
.
├── index.html          # 블로그 메인 페이지 (글 목록 + 웹앱 카드 목록)
├── CLAUDE.md            # 웹앱 추가 작업 사이클(Plan → Build → Review → Embed) 규칙
└── apps/
    └── 2048/            # 2048 퍼즐 게임
        ├── index.html
        ├── style.css
        ├── script.js
        ├── spec.md       # 설계 계획
        └── review.md     # 검증 결과
```

## 웹앱 목록

### [2048](apps/2048/index.html)
방향키(또는 모바일 스와이프)로 숫자 타일을 밀어서 합치는 퍼즐 게임입니다.

- 6x6(36칸) 보드
- 점수판(현재 점수 / 최고 점수, localStorage 저장)
- 빈 칸에는 귀여운 고양이 낙서 채워짐
- New Game으로 즉시 재시작
- 승리(2048 타일) / 게임 오버 판정

## 웹앱 추가 방식

새 웹앱은 [CLAUDE.md](CLAUDE.md)에 정의된 사이클을 따라 추가됩니다.

1. **Plan** — 서브에이전트가 계획을 세워 `apps/{앱이름}/spec.md`로 저장, 사용자 승인
2. **Build** — 서브에이전트가 `apps/{앱이름}/` 폴더 안에서 자체 완결된 구현
3. **Review** — 별도 서브에이전트가 브라우저에서 직접 검증, 문제 있으면 수정 후 `review.md` 작성
4. **Embed** — 블로그 메인 페이지에 웹앱 카드 추가, git 커밋

모든 웹앱은 `/apps/{앱이름}/` 폴더 안에서 완전히 자체 완결되며, 외부 라이브러리 사용은 최소화합니다(CDN은 허용).
